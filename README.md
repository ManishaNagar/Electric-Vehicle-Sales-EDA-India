# 📊 Electric Vehicle Sales Analysis in India (EDA)

## 📌 Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on Electric Vehicle (EV) sales data across different states in India.

The objective is to analyze EV adoption trends, identify high-performing states, and understand patterns in the growth of electric mobility using Python-based data analysis and visualization techniques.

This project showcases practical skills in:

- Data Cleaning  
- Exploratory Data Analysis (EDA)  
- Data Visualization  
- Trend Analysis  
- Comparative Analysis  
- Insight Generation
